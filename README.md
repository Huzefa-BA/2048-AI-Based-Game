# 2048-AI-Based-Game
As part of our final-year engineering project under the University of Mumbai, I collaborated with my teammates Monu Bind, Khushi Hajare, and Chitra Bhor to develop an AI-enhanced version of the popular 2048 puzzle game. The goal was to improve player engagement and performance by integrating artificial intelligence into the game’s decision-making process. The classic game requires users to combine tiles to reach higher numbers like 2048 or more, but many struggle due to the need for strategic foresight. To address this, we embedded an AI system capable of analyzing the game board in real time and recommending optimal moves, offering players a smarter and more interactive experience.

Our system is built using heuristic-based greedy algorithms, which evaluate all possible directions a move can take and assign heuristic scores based on multiple criteria such as the number of empty tiles, tile smoothness, monotonicity, and corner optimization. The system architecture is divided into three key modules: the Input Module captures the current grid and user interactions, the Processing Module applies heuristics to choose the best move, and the Output Module updates the board and interface accordingly. We also implemented features like an “AI Move” button for automated play, an Undo option, performance tracking, and score visualization to enhance usability and engagement.

Looking ahead, we aim to improve the game further by incorporating deep reinforcement learning, adaptive difficulty settings based on user skill levels, and multiplayer or AI-vs-AI tournament modes. This project not only demonstrates the practical use of AI in interactive environments but also serves as a platform for learning advanced decision-making strategies in real time.
